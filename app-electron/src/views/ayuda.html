Preguntas Frecuentes

●¿Cómo puedo recuperar o cambiar mi contraseña?

En caso de recuperar la contraseña, en la pestaña inicial del Login se verá un mensaje de “¿Olvido su contraseña?”, ahí se le pedirán sus datos, una vez ingresados le llegará un correo a su bandeja de entrada con un link, ahí se le pedirá ingresar su nueva contraseña. En caso de que se desee cambiar la contraseña desde adentro, se debe dirigir a configuraciones->Cambiar contraseña y seguir los mismos pasos.

●¿Puedo invitar a un usuario únicamente con el correo?

Sí, en el apartado de usuarios, solo se necesitara el correo de la persona que será invitada, a esta persona le llegara un correo en su bandeja de entrada con un link, se le pedirá una información y será creado su usuario

● ¿Cómo puedo registrar pagos?

Para poder registrar pagos, ya sea de una compra o de una venta, se debe ubicar en Finanzas -> Lista de órdenes -> "$". En este apartado se le pedirá rellenar una información como el monto del pago, la fecha del pago, el tipo de pago, ya sea una cuota o un pago completo y el historial de la orden, de igual manera un botón para poder registrar el pago.

●¿El software permite establecer diferentes niveles de acceso y permisos para los usuarios?

Sí, el software entiende los niveles de acceso, los cuales son: Gerente, Supervisor y empleado de almacén. Estos tienen distintos permisos y capacidades dentro del software, estos se pueden otorgar creando un usuario ya sea por invitación o manualmente.

●¿Qué tipo de capacitación se requiere para que un nuevo usuario aprenda a usar el software de inventario?

Sería necesario una capacitación básica, ya que el software tiene interfaces y una lógica bastante amigable para usuarios de primer uso, por lo que una capacitación de este nivel es suficiente para el aprendizaje de creación de usuario, registro de pagos y ordenes, administración de proveedores, clientes y usuarios y la creación de reportes.
